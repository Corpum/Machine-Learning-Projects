# Machine Learning & Deep Learning Projects

This repository contains a collection of Jupyter Notebooks focusing on fundamental machine learning and deep learning algorithms, feature engineering, and predictive modeling applications. 

## Project Structure & Descriptions

| `Carprice_predict.ipynb`| Aliyun Tianchi Challenge | Used Car Price Prediction | Full pipeline including data preprocessing, feature engineering (Target/Label Encoding, Standardization), and Feedforward Neural Network (FNN) modeling. |
| `BP.ipynb` | BP Neural Network | Implementation and experiments on Backpropagation (BP) neural networks. |
| `iris.ipynb` | Iris Classification | Classic Iris dataset classification using baseline machine learning algorithms. |
| `KNN.ipynb` | K-Nearest Neighbors | Implementation and evaluation of the K-Nearest Neighbors (KNN) algorithm. |
| `MINST_KNN.ipynb` | MNIST Digits (KNN) | Handwritten digit classification on the MNIST dataset using the KNN algorithm. |
| `MNIST.ipynb` | MNIST Digits Modeling | Comprehensive modeling and training pipeline for the MNIST handwritten digit dataset. |

## Important Note on Datasets & Execution Results

* **Datasets**: Not included in this repository to keep it lightweight. Please ensure you have the required datasets locally if you plan to re-run the notebooks.
* **Execution Results**: All code execution logs, training curves, evaluation metrics, and output visualizations are **pre-rendered and saved directly inside the `.ipynb` files**. You can view the results directly on GitHub/Gitee without executing the code locally.


## Requirements

If you wish to run the notebooks locally, the following environment and packages are recommended:

* Python 3.8+
* Jupyter Notebook / JupyterLab
* PyTorch / TensorFlow
* scikit-learn
* pandas
* numpy
* matplotlib
